# Phase 5: Plots

Phase 5 reads only Phase 4 release Parquet tables and makes reproducible figures under `release/`. Figures reproduce the Version 1 style emergence view and feature-profile overview, and add accepted evidence counts by species, yearly publication counts, and taxonomy composition. The feature-profile map uses IMSTE over the standardized V1 73-question species prevalence matrix; `species_feature_space_coordinates.parquet` stores the exact coordinates used by the figure and interactive explorer. The embedding does not assert or assign clusters. Rerunning this phase does not refetch articles or repeat Jev calls.
